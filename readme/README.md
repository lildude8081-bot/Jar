📖 GHIDUL UTILIZATORULUI (README)
=========================================

Bine ai venit în Linux Jar File Manager!

Aplicația folosește o metaforă vizuală unică:
* Stratul Superior: Folderele tale personale (~)
* Stratul Inferior: Nucleul sistemului (/)

UNELTE ȘI FUNCȚIONALITĂȚI RECENTE:
1. Căsuța de Filtrare: Tastează litere pentru a ascunde instant elementele parazite de pe ecran.
2. Monitor Hardware pe Culori: Bara de jos indică spațiul total liber în GB (Verde = Liber, Portocaliu = Peste 60% ocupat, Roșu = Critic sub 15% liber).
3. Scurtături de Tastatură:
   * [ F5 ] - Reîmprospătează instantaneu ambele liste din borcan.
   * [ Ctrl + N ] - Deschide direct utilitarul pentru a crea un Folder Nou în stratul activ.
4. Persistență Smart: Aplicația salvează automat ultima limbă folosită și pornește direct în ea.
5. Management: Folosește butoanele de pe capac pentru Mutare, Folder Nou, Ștergere și Redenumire.
6. Meniu Setări (⚙️): Permite comutarea fișierelor ascunse, a dimensiunilor și a Temei Luminoase.

📖 USER MANUAL (README)
=========================================

Welcome to Linux Jar File Manager!

The app uses a unique visual metaphor:
* Upper Layer: Your personal Home folders (~)
* Lower Layer: The system root foundation (/)

NEW TOOLS & ADVANCED FEATURES:
1. Instant Filter: Type characters to instantly hide unmatched files from the screen.
2. Smart Storage Monitor: The bottom bar indicates free space in GB using dynamic colors (Green = Safe, Orange = Over 60% full, Red = Critical below 15% free).
3. Hotkeys & Shortcuts:
   * [ F5 ] - Instantly refresh both panels inside the jar.
   * [ Ctrl + N ] - Open the Create New Folder utility directly in the active layer.
4. Auto-Save Language: The app saves your last selected language and boots directly into it.
5. Management: Use top-bar actions to Move, Create Folders, Delete, and Rename.
6. Settings Menu (⚙️): Toggle hidden files, calculate sizes, and switch to Light Mode.

📖 MANUALE UTENTE (README)
=========================================

Benvenuto in Linux Jar File Manager!

L'applicazione utilizza una metafora visiva unica:
* Strato Superiore: Le tue cartelle personali (~)
* Strato Inferiore: La radice del sistema operativo (/)

NUOVE FUNZIONALITÀ E STRUMENTI AVANZATI:
1. Filtro Istantaneo: Digita i caratteri per nascondere immediatamente i file non corrispondenti.
2. Monitor Hardware a Colori: La barra inferiore indica lo spazio libero in GB (Verde = Libero, Arancione = Oltre il 60% pieno, Rosso = Critico sotto il 15% libero).
3. Scorciatoie da Tastiera:
   * [ F5 ] - Aggiorna istantaneamente entrambi i pannelli nel barattolo.
   * [ Ctrl + N ] - Apre direttamente l'utilità Nuovo della cartella nello strato attivo.
4. Salvataggio Lingua: L'app salva automaticamente l'ultima lingua selezionata e si avvia direttamente in essa.
5. Gestione File: Usa i pulsanti in alto per Spostare, Nuovo, Eliminare e Rinominare.
6. Menu Impostazioni (⚙️): Attiva file nascosti, visualizza dimensioni e passa alla Chiara.
