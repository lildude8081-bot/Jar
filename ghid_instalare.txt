1. LOGICA DIN SPATELE ALIAS-ULUI (Comanda rapidă 'jar')
-------------------------------------------------------------------------------
Când am rulat comanda de automatizare pentru terminal, am modificat fișierul 
ascuns de configurare al terminalului tău local (~/.bashrc).

Ce am făcut mai exact?
Am adăugat următoarea linie la sfârșitul fișierului ~/.bashrc:
alias jar='python3 "/home/mihai/Lucruri Python/jar/main_window.py"'

Cum funcționează?
* De fiecare dată când deschizi un terminal nou, Bash citește acest fișier.
* Când tu scrii simplu cuvântul 'jar', terminalul îl înlocuiește automat în 
  fundal cu calea absolută către scriptul tău Python și îl execută.
* Comanda 'source ~/.bashrc' forțează terminalul curent să reîmcarce setările 
  pe loc, fără să mai fii nevoit să repornești calculatorul.

2. CUM SĂ ÎȚI PUBLICI PROIECTUL PE GITHUB (Pas cu Pas)
-------------------------------------------------------------------------------
GitHub este standardul industriei pentru publicarea codului. Pentru a-ți urca 
aplicația acolo, deschide un terminal în folderul proiectului tău:

Pasul A: Inițializează un depozit local Git
$ git init

Pasul B: Adaugă toate fișierele și folderele tale în sistemul de urmărire
$ git add .

Pasul C: Salvează stadiul actual al codului cu un mesaj profesionist
$ git commit -m "Initial commit - Fully modular v1.5.0 with language selector and storage monitor"

Pasul D: Mergi pe site-ul github.com, creează un cont, apasă pe "New Repository", 
numește-l "linux-jar-file-manager", iar site-ul îți va da o adresă web (URL).

Pasul E: Conectează folderul tău de pe Aura cu serverul GitHub (înlocuiește URL-ul):
$ git remote add origin https://github.com

Pasul F: Trimite codul tău în siguranță pe internet:
$ git branch -M main
$ git push -u origin main

3. ÎMPACHETAREA APLICAȚIEI (Cum o oferi altor utilizatori)
-------------------------------------------------------------------------------
Dacă vrei ca prietenii tăi sau alți oameni din comunitate să folosească Borcanul 
fără să deschidă terminalul sau să instaleze manual PyQt6, ai două opțiuni profesionale:

Metoda 1: PyInstaller (Creează un executabil de tip dublu-click)
Poți compila tot proiectul tău (cu tot cu iconițe, stiluri și logica din subfoldere) 
într-un singur fișier executabil binar independent.
* Instalează utilitarul:
  $ pip install pyinstaller
* Compilează aplicația (asigurându-te că incluzi folderul assets și nucleul core):
  $ pyinstaller --onefile --windowed --add-data "assets:assets" --add-data "core:core" --add-data "gui:gui" main_window.py
* În folderul nou numit 'dist/' care va apărea, vei găsi un fișier executabil curat. 
  Oricine îi dă dublu-click în Linux îi va porni aplicația instant!

Metoda 2: Crearea unui pachet nativ Debian/Ubuntu (.deb)
Aceasta este metoda supremă prin care aplicația ta se instalează direct în sistemul 
de operare (apare în meniul de aplicații de lângă Thunar, în categoria System Tools).
* Se creează o structură specială de foldere în stil Linux:
  /usr/bin/ (unde pui executabilul proiectului tău)
  /usr/share/applications/ (unde pui un fișier special numit 'jar-manager.desktop' 
  care conține numele aplicației, pictograma și comanda de pornire ca să apară în meniul Mint).
* Se împachetează folosind comanda nativă: 'dpkg-deb --build'. Utilizatorii tăi vor 
  instala Borcanul cu un simplu dublu-click prin managerul de aplicații nativ (Gdebi).

===============================================================================
 NOTĂ EXPLICATIVĂ: CONSTRUIREA ȘI REINSTALAREA INSTALATORULUI (MEMENTO AVANSAT)
===============================================================================

De fiecare dată când modifici codul sursă (în gui, core sau assets) sau când 
actualizezi manualul din folderul readme/, trebuie să urmezi o rutină simplă de 
două comenzi din terminal pentru a re-genera pachetul binar și a-l trimite direct 
în meniul tău global de aplicații Linux Mint:

Pasul 1: Construirea pachetului binar (.deb)
$ ./construieste_installer.sh
-------------------------------------------------------------------------------
* Ce face? Rulează scriptul tău automat care adună modulele împrăștiate, copiază 
  iconița cu murături în directorul grafic de pixmaps al sistemului, configurează 
  fișierul de control, scrie regulile de alias global în scripturile 'postinst' 
  și 'postrm', apoi rulează comanda nativă Linux 'dpkg-deb --build'.
* Rezultat: Scoate din cuptor fișierul curat 'linux-jar-file-manager_1.5.0_amd64.deb'.

Pasul 2: Reinstalarea curată direct în sistem
$ sudo apt install --reinstall ./linux-jar-file-manager_1.5.0_amd64.deb
-------------------------------------------------------------------------------
* Ce face? Cere managerului nativ de pachete APT să suprascrie vechea instalare 
  cu noul kit pe care tocmai l-ai compilat. Folosirea parametrului '--reinstall' 
  forțează Linux-ul să curețe versiunea precedentă și să ruleze din nou scriptul 
  de mentenanță 'postinst' în fundal.
* Rezultat: Actualizează pe loc pictograma cu borcanul, re-injectează alias-ul 
  global 'jar' în /etc/bash.bashrc și actualizează structura ferestrelor în 
  meniul sistemului (Applicazioni), fără a fi nevoie de repornirea calculatorului Aura.
